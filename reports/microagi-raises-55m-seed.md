## The Agency Play
- **What to build:** Partial functionality: robot-fleet telemetry + reliability dashboards and fine-tune pipelines for single factories using OSS MLOps - microagi's Atlas pattern minus the platform. Only viable with an industrial-engineering partner.
- **How to package it:** Fixed-scope pilot on one production cell, then per-line rollout retainer.
- **Suggested pricing:** Pilot $40-70k; per-line $15-25k; retainer $4-8k/mo.
- **First clients:** Mid-size German/Central-European manufacturers running cobot cells with downtime pain.
